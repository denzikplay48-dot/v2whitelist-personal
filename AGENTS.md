# Правила работы с репозиторием

- Не изменять файлы, не связанные с текущей задачей.
- Не запускать полную сборку APK без разрешения пользователя.
- Не менять `applicationId`, подпись приложения, версии зависимостей или конфигурацию сборки без согласования с пользователем.
- Сохранять работоспособность Android, Go, Xray и нативных компонентов.
- После изменений проверять diff и перечислять изменённые файлы.
- Не сохранять пароли, токены или ключи в репозитории.
